Final year project · BSc (Hons) Computing and Information Systems

IngredientFinder

A Recipe Ingredient Finder Mobile Application (Java), built as the final year project for my degree at Goldsmiths, University of London.

Programming languages used

  • Java
  • Json

Summary

IngredientFinder allows users to identify nearby markets and access information about available ingredients. The app's filtering capabilities enable users to search for particular ingredients and markets according to their needs.

Moreover, users can suggest markets not currently listed in the app, thereby contributing to the app's database and potentially benefiting both market owners and other users.
