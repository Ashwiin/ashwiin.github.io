Current · Full stack

MAVIS

Miles and Voucher Issuance System

The system behind Singapore Airlines' miles and voucher issuance for service recovery, including reporting, billing reconciliation and mass issuance. I'm a full-stack developer on it, working on the Angular front end and the Java Spring Boot back end.

  • Admin module for bulk voucher updates. Users upload an Excel file to move vouchers to statuses such as redeemed or void. A requestor submits the batch, an approver approves or rejects it, and approved changes are applied automatically. This replaced manual database updates by developers.
  • Customer email templates. Designed the voucher issuance email with its PDF, QR code and voucher details, along with the resend, redeemed and reinstated (refund) emails.
  • Angular

  • Spring Boot
  • MySQL

Completed · Backend

PODS

Pax Operational Data Distribution System

The platform that captures passenger transaction data from Amadeus Altea, enriches it, and distributes it to more than 35 downstream applications. I was a backend developer on it while its legacy TIBCO BusinessWorks services were moved to a cloud-ready architecture.

  • Microservices in production. Built services including Waitlist Reminder, Flight Loadsheet, and Excess Weight and Load Report in Spring Boot and Apache Camel, deployed on Red Hat OpenShift and AWS.
  • Design through to production. Wrote the designs and technical documentation, tested with JUnit and Mockito, supported SIT and UAT, and provided production support.

Bible study with answers that cite Scripture.
